## Not offered

The following former platform feature is **not offered** on the current {{site.data.tenant.name}} host: The platform VPN Agent service and its setup/API endpoints. Its setup and installation recipe has been removed so it is not mistaken for a supported deployment path.

No OpenVPN configuration can be obtained from this retired recipe. A separately managed network tunnel is not a platform Agent feature.

See [Node.js component authoring](/developers/building-nodejs-component.html) and [component intake](/developers/deploying-component.html).

Runtime and deployment validation remain **UNVERIFIED** pending [issue #64](https://gitlab.com/TECHeGO/thatapp-ai-powered/-/issues/64).
