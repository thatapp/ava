## Not offered

The following former platform feature is **not offered** on the current {{site.data.tenant.name}} host: Java component hosting and the Sailor JVM/Gradle build service. Its setup and installation recipe has been removed so it is not mistaken for a supported deployment path.

A Java runtime decision is tracked separately. Java software required by an external vendor is a separate prerequisite and does not establish Java hosting support here.

See [Node.js component authoring](/developers/building-nodejs-component.html) and [component intake](/developers/deploying-component.html).

Runtime and deployment validation remain **UNVERIFIED** pending [issue #64](https://gitlab.com/TECHeGO/thatapp-ai-powered/-/issues/64).
