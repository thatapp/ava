## Component authoring

The current host loads JavaScript component entry points. Use [Node.js component authoring](/developers/building-nodejs-component.html), [the descriptor reference](/developers/component-json-technical-reference.html) and [reviewed component intake](/developers/deploying-component.html).

Java component hosting, the old Java SDK/build service, a first-party platform CLI and customer git-push deployment are **not offered**. The old Maven coordinates and mandatory renamed npm packages are not supported installation instructions and have been removed. No package-registry availability claim is made here.
